> **BlogCrafts AI** is an AI-augmented content creation and editorial workflow application built with **React**, **TypeScript**, and **Tailwind CSS**. It assists creators in generating SEO-optimized articles, structuring outlines, and refining copy.

---

## ✨ Features

- 🧠 **AI Content Generation:** Generate complete, structured articles with automated headings and meta summaries.
- 📝 **Markdown Live Preview:** Real-time side-by-side markdown editing with syntax highlighting.
- 🎨 **Modern Minimalist UI:** Distraction-free writing environment styled with Tailwind typography.

---

## 🚀 Quick Start
```bash
git clone https://github.com/sangamesh5588/blog-crafts-ai.git
cd blog-crafts-ai
npm install
npm run dev
```
